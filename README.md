# 급여DB 통합 도구

## 변경 내용

- ERP `.xls`를 LibreOffice Calc로 `.xlsx` 통합문서 전체 변환합니다. pandas 값 재출력은 사용하지 않습니다. 변환본만 다운로드할 수도 있습니다.
- Streamlit Cloud는 `packages.txt`의 `libreoffice-calc`, `fonts-nanum` 설치가 필요합니다. 설치되지 않았거나 변환이 실패하면 서식을 버리는 방식으로 우회하지 않고 오류를 표시합니다.
- 열 제목에서 부서/성명/입사일/직종/수당을 찾습니다. 제목이 중복되거나 인식되지 않으면 사용자가 열을 선택해야 하며 기존 열 번호로 추측하지 않습니다. 제목 행과 처리할 시트도 선택할 수 있습니다.
- 확인된 DB 수당 제목: `조출점심저녁OT`, `연장수당`, `야간수당`, `휴일수당(1)`.
- 업무상 대응관계: OT K열 → 조출점심저녁OT, M열 → 연장수당, O열 → 야간수당, Q+S열 → 휴일수당(1). 현재 매칭은 기존 기능대로 OT 총금액(기존 T열의 제목을 선택)과 DB 4개 수당 합계를 비교합니다. OT 개별 수당을 DB에 덮어쓰지는 않습니다.
- 차액 계산의 기준금액/차감1/차감2는 실제 제목 미확인 상태이므로 화면에서 선택합니다. 기존 결과 위치 AU/X/AS에 각각 배치합니다.

## 결과 파일 호환성

첫 번째 활성 시트 `급여통합결과`에 완성된 급여DB를 만듭니다. 원본 시트는 같은 파일 안에 그대로 보관합니다.

| 위치 | 내용 |
|---|---|
| B / D / F / K | 부서 / 성명 / 입사일 / 직종 |
| Q:T | 조출점심저녁OT / 연장수당 / 야간수당 / 휴일수당(1) |
| U | 4개 수당 합계 |
| V | 이름+입사일+본부로 매칭한 OT 금액 |
| W | 일치 여부 (미매칭은 명시적으로 표시) |
| X / AS / AU | 차감1 / 차감2 / 기준금액 |
| AV | `AU-X-U-AS` |

그 외 원본 열은 남는 자리에 원래 상대 순서로 배치합니다. 다른 열의 절대 위치까지는 보장하지 않습니다. 원본 헤더 이전 안내 행 및 합계 행은 결과에서 제외하며 원본에는 남습니다. 원본 수식 셀은 원본 시트 해당 셀을 참조하여 임의 열 이동으로 수식을 변형하지 않습니다. Excel에서 파일을 열 때 재계산하도록 설정합니다. Excel을 열지 않고 결과 수식의 캐시만 읽는 후속 도구는 재계산 후 저장이 필요합니다.

`대조내역` 시트에는 원본 행 번호, 합산/매칭 금액, 차액의 계산값, 미매칭/금액 불일치/입사일 오류 등의 사유를 기록합니다. 기존 원본 시트명이 결과 시트명과 같으면 openpyxl이 새 시트명에 번호를 붙입니다.

급여명세서 문구는 기존 BA:BE에 생성하며 이미 값이 있으면 중단합니다. 시간 항목은 열 제목으로 선택합니다. 원본 열을 임의로 숨기지 않습니다.

## 검증과 제한

- `python -m pytest -q` 실행 (테스트 의존성: pytest, xlwt).
- Ubuntu CI에서 LibreOffice를 설치하여 실제 XLS의 두 시트, 병합, 날짜, 굵은 글씨/채움색/열너비, 수식과 계산값을 검증합니다.
- 실제 ERP 급여 파일은 제공되지 않았습니다. 복잡한 도형, 인쇄 배치, 외부 연결, 암호화 파일까지 Excel과 동일한 변환을 보장하지 않습니다. 배포 전 실제 ERP 샘플로 확인해야 합니다.
- 원본을 보관하더라도 openpyxl 저장 과정에서 지원하지 않는 Excel 확장 기능은 보존되지 않을 수 있습니다.
- 중복 OT 키는 작업을 중단합니다. 부서를 추정하여 다른 본부의 동명이인과 매칭하지 않습니다. 0원은 유효한 금액이며 누락 금액과 구분합니다.
- 업로드 자료는 사용자 세션과 변환용 임시 디렉터리에서 처리합니다. 변환 임시 디렉터리는 처리 종료 시 삭제합니다.
- 운영 main 병합/배포는 사용자 승인 후 진행합니다.
